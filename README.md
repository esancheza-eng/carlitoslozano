# AGRO-MOTOR — Sitio web

Sitio web estático para **AGRO-MOTOR · Maquinaria Agrícola y Accesorios**.

## Características

- Diseño responsive para celular, tablet y PC.
- Catálogo de productos basado en las imágenes proporcionadas.
- Sin carrito de compras.
- Sin checkout.
- Sin precios inventados.
- Pedidos y consultas directamente por WhatsApp.
- Buscador de productos.
- Secciones de Nosotros, Misión, Visión, Servicio Técnico, Cobertura y Contacto.
- Botón flotante de WhatsApp.

## Publicar en GitHub Pages

1. Crea un repositorio, por ejemplo `agro-motor`.
2. Sube `index.html`, `styles.css`, `script.js` y la carpeta `assets`.
3. En GitHub entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona `main` y la carpeta `/root`.
6. Guarda y espera a que GitHub publique el sitio.

No cambies los nombres de los archivos dentro de `assets` si no vas a actualizar las rutas en `index.html`.
